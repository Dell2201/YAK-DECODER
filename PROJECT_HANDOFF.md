# YAK Decoder v3 — контекст проекта

Проект — локальный Windows x64 интерфейс для декодирования PHP после YAK Pro 3.x. Версия комплекта — v3; надпись в интерфейсе сейчас `0.31`. Основное пользовательское описание и запуск — в README.md.

## Состав

- `public/index.html`, `public/assets/` — редактор, выбор версии PHP, пакетная обработка, ZIP, статистика и журнал.
- `public/decode.php` — HTTP endpoint, проверка запроса и подписи.
- `app/DecoderProcess.php` — запуск worker, ограничения процесса и обязательная проверка выходного кода через выбранный PHP.
- `app/worker.php` — ввод через STDIN, вызов декодера, JSON-ответ и счётчики переходов.
- `lib/decoder/Deobfuscator.php` — разбор и печать AST, обработка регионов и проверка сохранности.
- `lib/decoder/CfgStructurer.php` — построение графа переходов и восстановление управляющих конструкций.
- `lib/decoder/vendor/php-parser5/` — PHP-Parser 5; `runtime/` — переносимые PHP и лицензии.
- `tests/cases/` — сложные стресс-наборы и регрессии; команды и состав — в `tests/cases/README.md`.

`start.cmd` запускает сервер PHP 7.4.33 с `-n` на 127.0.0.1:18090. Выбранная версия 7.4/8.1/8.2/8.3 передаётся worker и задаёт версию разбора и печати; выход проверяет отдельный PHP той же версии. Отсутствие выбора означает 7.4. Сервер не исполняет пользовательский код.

## Обработка и ограничения

Фильтр подписи проверяет точное вхождение `Obfuscated by YAK Pro - Php Obfuscator`. В пакетном режиме используются общий выбор PHP и флажок подписи. Поддерживаемые файлы с PHP-тегами обрабатываются рекурсивно; остальные копируются. Архив собирается в браузере, сохраняет пути и пустые папки. При частичном результате, предупреждении или ошибке создаётся текстовый отчёт с путями.

Декодирование перестраивает поток управления, но может оставить `goto`, если безопасно восстановить участок не удаётся. Не отключайте проверки полезной нагрузки AST и корректности сохранившихся переходов ради уменьшения счётчика. Синтаксическая проверка сама по себе не гарантирует эквивалентность поведения. При проверке поведения сравнивайте с обфусцированным входом: YAK может изменить поведение исходника при обфускации.

Покрытие ограничено подготовленными примерами. В наборах A и B проверены 175 вариантов YAK Pro 3.0.2, в прежнем наборе — ещё 25. Успешные проверки не гарантируют поддержку любого входа. Запускайте для сравнения поведения только известные безопасные тестовые программы.

Дополнительные детали алгоритма и регрессий — в `HANDOFF_DECODER_FIXES.md`. Источники и контрольные суммы runtime — `runtime/syntax-runtimes.json`.
