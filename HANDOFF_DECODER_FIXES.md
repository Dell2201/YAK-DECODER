# YAK Decoder 2.x — исправления декодера

Краткое описание текущих механизмов и регрессий. Архитектура — в [PROJECT_HANDOFF.md](PROJECT_HANDOFF.md), запуск проверок — в [README.md](README.md).

## Восстановление управления потоком

### Независимые регионы и безопасный частичный результат

`Deobfuscator` обрабатывает вложенные тела отдельно. Отказ одного тела не отменяет успешные преобразования независимых тел. При этом `keptGotosAreStable` отклоняет преобразование, если оставшийся goto ссылается на метку удалённого региона. Проверка полезных узлов AST запрещает потерю или дублирование выражений. Неподдержанный регион сохраняет исходную структуру.

### Циклы и многоуровневые переходы

`CfgStructurer` разрешает пустые цепочки goto перед переходом к следующему блоку и учитывает внешние выходы при определении региона цикла. Выделенный блок инкремента позволяет восстановить `for` и корректно направить `continue` на инкремент. Цепочка родительских циклов определяет `break N` и `continue N` как для явных переходов, так и для fall-through.

### Контекст вложенных тел

`attachBodyControls` и `attachNestedControls` передают отображение меток на break/continue через условия, циклы, switch и try/catch/finally. Try/catch/finally не добавляют уровень вложенности управления. Цели внешнего for включают блок инкремента, а не только заголовок. Границы функций и замыканий не пересекаются.

`processNested` повторно обрабатывает тела for/while/do/foreach, switch, try, catch и finally с полученным контекстом. `stripStaleControls` очищает атрибуты предыдущих попыток перед новой обработкой региона.

### Ветвление в конце цикла

Переход из ветви в заголовок текущего цикла выражается через continue. Если обе ветви исчезают из-за stop-набора, регион отклоняется вместо потери условия. Это покрывает регрессию `tfc-latch-obfuscated.php`.

## Проверенные регрессии

Среда: PHP 7.4.33, PHP-Parser 4.19.4, YAK Pro 2.0.17. Результаты относятся к указанным программам и профилям обфускации.

| Набор | Результат |
|---|---|
| `examples/stress-yak-obfuscated.php` | 403 → 0 goto; сравнение поведения по нескольким seed |
| `tests/fixtures/mini-*-obfuscated.php` | Вложенные циклы, switch, break/continue нескольких уровней: 0 goto |
| `tests/fixtures/tfc-latch-obfuscated.php` | 78 → 0 goto, поведение сохранено |
| `tests/fixtures/crosslevel-test.php` | 3 → 3 goto, ожидаемый защитный откат, поведение сохранено |
| `tests/cases/stress-b-php74/` | 50 вариантов, суммарно 3800 → 0 goto, 350 сравнений обфусцированного и декодированного кода без расхождений |

В стресс-наборе используются два безопасных сценария: рекурсивный граф/генераторы/вложенные циклы и клонирование/повторные попытки/catch/finally. Достигнуты все 9 и 10 заданных маркеров. Профиль: обфускация условий, циклов, строк и меток, перемешивание блоками по одному statement; переименование остальных имён выключено.

`run_tests.py` возвращает ненулевой код при оставшихся goto, расхождениях поведения или недостигнутых маркерах; `results.json` сохраняет детали вариантов. Обычный прогон использует сохранённые входы; `--yakpro` создаёт свежие варианты.

Базовый `final_check.ps1` содержит 25 проверок. `portable_runtime_test.py` проверяет автономный runtime и 29 HTTP-сценариев. Пакетные тесты проверяют пути, бинарные данные, пустые папки, отчёт и ZIP независимым reader. Эти тесты дополняют сравнение поведения, а не заменяют его.

## Что сохранять при дальнейших изменениях

- Совместимость с PHP 7.4 и конструкторами PHP-Parser 4.
- Payload-проверки, проверку стабильности оставшихся меток и откат региона.
- Порядок побочных эффектов, семантику break/continue и выполнение finally.
- Сравнение с обфусцированным входом, а не автоматическое исправление ошибок YAK.
- Отдельную проверку выходного синтаксиса до выдачи результата пользователю.

Старый шаблонный путь unshuffle/build удалён; актуальная реализация восстановления структуры находится в CFG-коде. Поддержка произвольных goto, PHP 8 или PHP-Parser 5 этим набором не подтверждается.
