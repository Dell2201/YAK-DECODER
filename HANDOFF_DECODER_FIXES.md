# YAK Decoder v3 — устройство декодера

Документ предназначен для доработки `lib/decoder/Deobfuscator.php` и `CfgStructurer.php`. Общая архитектура и запуск описаны в `PROJECT_HANDOFF.md`.

## Преобразование

`Deobfuscator` разбирает вход PHP-Parser 5 с выбранной версией PHP, обходит вложенные тела и передаёт регионы с метками и `goto` в `CfgStructurer`. Тот строит граф базовых блоков, определяет циклы и ветвления и формирует структурированный код. Печать использует ту же выбранную версию PHP. Worker возвращает количество узлов `goto` до и после обработки; оно вычисляется по AST, а не токенизатором PHP 7.4.

Успешные вложенные преобразования сохраняются при неудаче внешнего региона, когда это безопасно. Проверки полезной нагрузки и `keptGotosAreStable` защищают от потери выражений и переходов к удалённым меткам. Если регион нельзя безопасно перестроить, он сохраняется с переходами. `php --syntax-check` проверяет итоговый синтаксис, но не семантику.

## Сложные переходы

`attachBodyControls` передаёт информацию о целях переходов вложенным циклам, `switch` и `try/catch/finally`. Последние не добавляют уровень для `break`/`continue`. Для восстановленного `for` переход к блоку инкремента означает продолжение цикла. Контекст не должен пересекать границы функций и замыканий; устаревшие временные атрибуты удаляются перед повторной обработкой.

Регрессии переходов между уровнями, через `finally`, внутри `catch` и случай latch находятся в `tests/cases/regressions/`. Сложные наборы с исходниками, обфусцированными файлами и результатами — в `tests/cases/stress-legacy/`, `stress-a/` и `stress-b/`. `stress-a/upstream-errors/` содержит отдельно случаи, в которых сам YAK испортил вход при переименовании; они не входят в успешный прогон.

## Проверка изменений

Из корня проекта:

```text
python tests/php8_stress_test.py
python tests/stress_suite_b_test.py
python tests/php_version_test.py
powershell -NoProfile -File tests/final_check.ps1
```

Стресс-наборы A и B проверяют 75 и 100 вариантов соответственно, синтаксис, отсутствие оставшихся `goto` в этих случаях и совпадение поведения с обфусцированным входом. Подробности и команды — `tests/cases/README.md`. Сохраняйте тесты на ранний выход, многоуровневые `break`/`continue`, побочные эффекты и порядок выполнения `finally`. Используйте только специально подготовленные безопасные программы для запуска.

В исследованном примере YAK Pro 2.0.17 изменял поведение `do/continue` по сравнению с исходником; декодер должен сохранять поведение полученного обфусцированного файла. Результаты тестов ограничены проверенными входами.
