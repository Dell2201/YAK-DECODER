# Сложные тестовые примеры декодера

Единый каталог вместо прежних fixtures и primer. В каждом наборе исходники, результаты обфускации YAK Pro, сохранённые результаты декодера и метаданные лежат рядом.

| Папка | Назначение |
|---|---|
| stress-legacy | Прежний общий стресс-тест PHP 7.4: stress.source.php, 25 обфускаций и 25 результатов, конфигурация и исторические результаты проверки |
| stress-a | 75 сложных обфускаций PHP 8.1/8.2/8.3, три исходника, результаты, manifest, конфигурации и описание |
| stress-b | 100 сложных обфускаций PHP 7.4/8.1/8.2/8.3: генераторы, Fiber, рекурсия, readonly clone, try/catch/finally; четыре исходника и результаты |
| regressions | Четыре воспроизведения ошибок: переходы между уровнями, foreach/finally/continue внешнего цикла, try/catch/switch с многоуровневыми выходами и latch реального метода |
| stress-a/upstream-errors | Отдельные примеры, испорченные самим YAK при полном переименовании нового синтаксиса. В успешный регрессионный прогон не входят |

Простые core/mini/ww/sw/tri/do_continue и отдельные демонстрации syntax-goto удалены. Короткие регрессии сохранены из-за сложности переходов, которые они проверяют. Тестовые данные не нужны для запуска сайта.

## Запуск из корня проекта

```text
python tests/php8_stress_test.py
python tests/stress_suite_b_test.py
python tests/php_version_test.py
powershell -NoProfile -File tests/final_check.ps1
```

Первый скрипт проверяет 75 вариантов A, второй — 100 вариантов B. Оба проверяют декодирование, lint и поведение. Для быстрого прогона B добавьте --quick. Параметр --update-snapshots обновляет сохранённые результаты B после проверок.

php_version_test.py проверяет выбор PHP, фильтр подписи и регрессии finally/try/catch на всех четырёх runtime. final_check.ps1 проверяет прежний общий стресс-тест из examples, latch, предохранитель внешних переходов и демонстрационный код сайта.

Сохранённые *.decoded.php служат примерами результата; стресс-скрипты каждый раз декодируют вход заново. Успех этих тестов не гарантирует поддержку произвольного PHP-кода. Выполнять неизвестные пользовательские файлы для сравнения поведения нельзя.
