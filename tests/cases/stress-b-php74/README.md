# Стресс-тесты PHP 7.4

Два безопасных сценария: graph-nested.original.php проверяет рекурсивный граф, генераторы и вложенные циклы; clone-retry.original.php — клонирование, повторные попытки, catch и finally.

Для каждого сохранены 25 вариантов YAK Pro 2.x и результаты декодера. Профиль yakpro-2.cnf: условия, циклы, строки, метки и перемешивание включены; переименование остальных имён выключено.

Запуск из корня проекта:

    python tests/cases/stress-b-php74/run_tests.py

Скрипт заново декодирует сохранённые входы, обновляет *.decoded.php и results.json. Сравнивает stdout, stderr и код возврата исходника, обфусцированного файла и результата на seed -7, -1, 0, 1, 3, 11, 42. Требует успешный lint, ноль goto и достижение всех заданных маркеров. При провале возвращает ненулевой код; запускайте Python без -O, чтобы сохранялись все проверки assert.

Создать свежие обфускации:

    python tests/cases/stress-b-php74/run_tests.py --yakpro ПУТЬ/К/yakpro-po.php

Нужен YAK Pro 2.x. Другие проекты не требуются. Скрипт исполняет только специально подготовленные тестовые программы.

Проверенный результат: 50 вариантов, 3800 → 0 goto, 350 сравнений обфусцированного и декодированного кода без расхождений; исходники также совпали по поведению. Покрыты все 9 и 10 маркеров. Это результат конкретных входов и настроек, не гарантия для произвольного PHP.
