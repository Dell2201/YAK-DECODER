# Расширенные стресс-тесты PHP 8.1 / 8.2 / 8.3

Три исходника находятся в tests/cases/stress-a/php81-stress-original.php, php82-stress-original.php и php83-stress-original.php. Это расширения прежнего полного stress-original: if/else/elseif, вложенные for/while/do/foreach, switch, break/continue на несколько уровней, побочные эффекты условий, try/catch/finally, замыкания, классы и строки. В версии 8.1 добавлены enum, readonly-свойства, intersection type и first-class callable; 8.2 — readonly-класс, DNF-типы, standalone true/false/null; 8.3 — типизированные константы, Override и readonly clone reinitialization. Новый синтаксис участвует в вычислениях, а не просто присутствует в декларациях.

Для каждой версии созданы 25 свежих случайных обфускаций YAK Pro 3.0.2: всего 75 входов. Сохранены в tests/cases/stress-a вместе с декодированными результатами, конфигурациями и manifest.json. Используется целевой parser_mode 8.1/8.2/8.3. Перемешивание выполняется минимальными блоками, условия/циклы превращаются в goto, строки скрываются. Переименование имён отключено для получения исполняемого входа — причины ниже. Это не максимальная обфускация всех категорий.

## Новое ограничение декодера

В versionFeature тестов 8.1 и 8.3 не полностью преобразуются переходы через try/finally → foreach → внешний for с многоуровневым break/continue. Диагностика: unknown jump target, затем cross-level goto in kept nested body. Срабатывает откат к исходной структуре региона: поведение на тестовых входах сохранено, но goto остаются. Не следует отключать защиту ради нулевого счётчика. Эти примеры служат воспроизведением для дальнейшей доработки; это ограничение сочетания конструкций, не всех файлов PHP 8.1 или 8.3.

## Отдельные ограничения YAK Pro 3.0.2

Полное переименование имён было проверено отдельно. Полученные входы завершаются ошибками ещё до декодирования:

- 8.1: Class not found при обращении к enum;
- 8.2: TypeError при DNF/intersection type после переименования интерфейсов;
- 8.3: Undefined property / Cannot create dynamic property в readonly-классе с promoted-свойством.

Исходные примеры исполняются успешно. Неисправные обфусцированные входы и соответствующие configs сохранены в tests/cases/stress-a/upstream-errors. Они не включены в успешные 525 сравнений. Декодер не обязан восстанавливать логику, уже испорченную обфускатором.

На исполняемом профиле обфускации исходник до YAK и код после YAK для seed 0 различаются только полем do — ранее известный do/continue. Поэтому эталон декодирования — обфусцированный вход.

## Повторный запуск

Из корня Yak-pro v3:

```text
python tests/php8_stress_test.py
```

Тест заново декодирует сохранённые 75 обфусцированных входов через DecoderProcess, проверяет синтаксис и поведение. Частичные результаты учитываются отдельно, успех сравнения поведения не выдаётся за полное удаление goto. Исполняются только эти известные тестовые программы, не произвольные модули.
