Для каждой версии создано 25 свежих обфускаций настоящим YAK Pro 3.0.2. Всего 100 вариантов, 700 сравнений на seed -7, -1, 0, 1, 3, 11, 42; каждый запуск обрабатывает ещё шесть смещений seed. Обфусцированный код и результат декодера совпадают по stdout/stderr/коду возврата. Все входы и результаты проходят синтаксическую проверку соответствующим PHP. В этом наборе также не обнаружено отличий между исходником до YAK и обфусцированным кодом на этих входах. Все 43 заданных маркера достигнуты.

Профиль YAK: минимальные перемешиваемые блоки, обфускация условий/циклов/строк, случайные имена меток; переименование остальных имён отключено из-за ранее выявленных проблем самого YAK с новым синтаксисом. Конфигурации сохранены рядом с примерами.

## Исправление декодера

Ранее nested82 оставлял 19 goto, retry83 — 49. Исправлено распространение контекста циклов в CfgStructurer::attachBodyControls и Deobfuscator::processNested. Вложенные try, catch и finally получают цели внешних break/continue, но не добавляют уровень вложенности. Предварительно восстановленные for/while/do также передают этот контекст своим телам. Между функциями и замыканиями контекст не передаётся.

Защита payload и keptGotosAreStable сохранена. Все 100 вариантов теперь требуют ноль goto и точное совпадение поведения. Отдельная минимальная регрессия tests/cases/regressions/try-catch-loop-controls.php проверяет вложенные циклы, switch внутри catch, продолжение внешнего цикла, выход через finally и код после внутреннего цикла на PHP 7.4/8.1/8.2/8.3.

Счётчик worker исправлен: gotoBefore и gotoAfter берутся из AST выбранного PHP-Parser, а не из token_get_all PHP 7.4. На PHP 8.3 входах корректно возвращается 84 вместо 0. Строки с текстом goto не считаются переходами. Независимый подсчёт целевым runtime в тестах сохраняется и обязан совпадать с ответом приложения.

## Повторный запуск

```text
python tests/stress_suite_b_test.py
python tests/stress_suite_b_test.py --quick
```

Полный режим проверяет все 100 сохранённых входов, quick — по одному для каждой версии. Проверяются lint, совпадение поведения, покрытие всех заданных hit-маркеров; остаточные goto и расхождения счётчиков приводят к ошибке теста. Чтобы обновить сохранённые decoded-файлы и manifest после полного успешного прогона, используйте --update-snapshots.

Исходники: tests/cases/stress-b/*.php.
100 обфусцированных входов, сохранённые результаты, configs, manifest.json: tests/cases/stress-b/.

Это проверки только специально написанных программ. GitHub и релиз не обновлялись.
