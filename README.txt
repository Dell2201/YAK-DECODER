YAK Decode

Декодер ориентирован на код, обфусцированный YAK Pro из ветки 2.x:
https://github.com/pk-fr/yakpro-po/tree/2.x
Ветка master YAK Pro использует PHP-Parser 5 и отдельно не заявлена
как поддерживаемая версия обфускатора.

Запуск на этом компьютере
1. Дважды щёлкните start.cmd.
2. Откроется http://127.0.0.1:8090.
3. Вставьте код в поле и нажмите «Декодировать» или Ctrl+Enter.
   Результат заменит код в том же поле. Доступна кнопка «Вернуть исходник».
4. Для остановки нажмите Ctrl+C в окне сервера.

Над полем есть флажок «Обрабатывать только код с подписью YAK Pro».
По умолчанию он снят: допускается любой PHP-код.
Когда флажок установлен, до запуска декодера проверяется точное вхождение
строки Obfuscated by YAK Pro - Php Obfuscator (с учётом регистра).
Проверка выполняется и в браузере, и на сервере. Версия и дата в шапке
могут быть любыми. Без нужной строки код остаётся в поле, выводится ошибка.
Проверяется только наличие строки, а не подлинность происхождения кода.

Пакетное декодирование папки
Ниже редактора находится блок «Пакетное декодирование папки».
Перетащите папку в выделенную область,
затем нажмите «Декодировать и скачать zip».
Используется тот же флажок проверки подписи, что и для одного фрагмента.
Обрабатываются .php, .php0–.php9, .phtml, .inc и .tpl с PHP-тегами.
Файлы рассматриваются целиком, в том числе с HTML перед PHP-тегами.
При включённом флажке файлы без точной подписи сохраняются без изменений.
Остальные типы файлов, включая изображения, XML, Twig, CSS, JavaScript,
лицензии и скрытые файлы, переносятся байт в байт без фильтрации.
Пути сохраняются вместе с именем выбранной корневой папки.
При ошибке декодирования или php --syntax-check в ZIP остаётся исходник;
частичный результат с оставшимися goto помечается отдельно в таблице.
Не-UTF-8 PHP и PHP больше 2 МБ также сохраняются исходными с предупреждением.
Архив скачивается автоматически; ссылка повторного скачивания остаётся.
Если остались goto, есть предупреждения или ошибки, в корне ZIP создаётся
yak-decoder-report.txt с путями и причинами по отдельным разделам.
Исходная папка на диске не изменяется. Обработку можно остановить.

Лимиты: до 5000 файлов, 100 МБ на входе, 150 МБ суммарного результата,
не более 10000 записей ZIP с учётом папок. ZIP использует метод STORE
(без сжатия), UTF-8 имена и CRC-32. Дополнительные библиотеки не нужны.
Пустые папки сохраняются в ZIP вместе с остальной структурой.
На сервер передаются только подходящие PHP-файлы по одному; ZIP собирается
в браузере. Папки и файлы не извлекаются на сервере по пользовательским путям.

В комплект включён PHP 7.4.33 NTS для Windows x64 и библиотеки Visual C++.
Установка PHP на компьютере и настройка PATH не требуются.
Composer и подключение к интернету для работы не требуются.
Сайт содержит собственную копию исправленного декодера и PHP-Parser.

Структура
public/          корневая папка веб-сервера
public/decode.php  JSON-обработчик запросов
app/             запуск отдельного процесса декодирования
lib/decoder/     Deobfuscator.php, CfgStructurer.php, PHP-Parser
runtime/php/     встроенный PHP 7.4.33 и его библиотеки

На другом сервере укажите public/ как DocumentRoot.
На Windows сайт предпочитает runtime/php/php.exe для декодирования
и проверки синтаксиса. start.cmd запускает веб-сервер этим же PHP.
Используется флаг -n: системные php.ini не влияют на работу комплекта.
Если встроенного Windows PHP нет, для другого сервера путь к PHP CLI
можно задать серверной переменной YAK_PHP_BINARY.
Для внешнего размещения используйте полноценный веб-сервер с HTTPS;
встроенный сервер PHP из start.cmd предназначен для локального запуска.

Входной код не исполняется: он передаётся парсеру через стандартный ввод.
Результат отдельного процесса временно буферизуется в системной папке
и удаляется после ответа. Сайт не отправляет код сторонним сервисам.
Лимит входа — 2 МБ; процесса — 512 МБ памяти, около 25 секунд обработки.

Каждый успешный результат обязательно проверяется PHP CLI командой
php --syntax-check (эквивалент php -l) до возврата пользователю.
Проверяется временный файл с выходным кодом; после проверки он удаляется.
Лимит проверки — 5 секунд. Используется тот же PHP CLI, что и у декодера.
Если проверка не пройдена, исходный код остаётся в поле и выводится ошибка.
Проверка синтаксиса не исполняет PHP-код и не проверяет его бизнес-логику.

Если остаются goto, страница показывает предупреждение: декодер сохранил
неподдержанный участок. Имена переменных автоматически не восстанавливаются.
Сайт сохраняет поведение поданного PHP; ошибки самого обфускатора
не исправляются автоматически.
